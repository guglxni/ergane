# Security Policy

## Supported version

Security fixes are applied to the latest `master` branch.

## Reporting a vulnerability

Please do not open a public issue for a potential vulnerability. Use GitHub's
private security advisory flow for this repository, including a minimal proof of
concept, affected version or commit, and reproduction steps. We will acknowledge
reports within 7 days and coordinate remediation before disclosure.

## Security boundaries

Ergane processes code diffs and can send derived text to patent APIs and OpenAI.
Private GitHub repositories are blocked from external processing unless an
operator explicitly opts in. Ergane never files patents or takes legal action
automatically; generated claims require attorney review.
