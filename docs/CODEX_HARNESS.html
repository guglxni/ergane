2.1 Pro Mode (Separate from Effort)

Pro mode performs more model work before returning a single answer. It is independent of reasoning effort.

  • Standard mode (default): Normal reasoning pipeline
  • Pro mode (reasoning.mode: "pro"): Extra verification, exploration, refinement. Higher latency + token cost. Billed at standard rates.
Ergane rule: Use pro mode only for Stage 3 (Verifier) claim drafting when novelty score ≥ 0.7. Standard mode for all other stages. Never use pro mode for Luna/Terra — cost outweighs benefit.

2.2 Ultra Mode (Codex Desktop / Multi-Agent Beta)

ultra coordinates 4 parallel agents by default (configurable up to 16). Available in:

  • ChatGPT Desktop: Pro/Enterprise users
  • Codex CLI: Plus and higher plans
  • Responses API: Multi-agent beta (programmatic)
Ergane ultra strategy: For a single commit scan, spawn 4 parallel subagents:
(1) Luna — diff parsing | (2) Terra — Coral SQL generation | (3) Terra — USPTO direct search | (4) Luna — EPO search
Then Sol synthesizes all 4 outputs. Wall-clock time drops ~60% vs sequential.

3. GPT-5.6 API Features for Ergane

3.1 Programmatic Tool Calling (PTC)

What it does
GPT-5.6 writes JavaScript to call eligible tools, pass results between calls, and process intermediate outputs in a hosted runtime. ZDR-compatible. No container costs.
When Ergane uses it
  • Stage 2 (Implementer): PTC script fetches USPTO + EPO + PQAI in parallel, joins results, deduplicates patent numbers, returns ranked JSON
  • Stage 4 (Reviewer): PTC script validates webhook payload schema against OpenClaw JSON5 schema before POST
{
  "model": "gpt-5.6-terra",
  "tools": [{
    "type": "programmatic_tool_calling"
  }, {
    "type": "function",
    "function": {
      "name": "search_uspto",
      "description": "Search USPTO patent database"
    },
    "allowed_callers": ["direct", "programmatic"]
  }],
  "input": "Search USPTO, EPO, and PQAI for 'distributed cache invalidation', deduplicate by publication number, rank by combined score. Return JSON."
}

3.2 Explicit Prompt Caching

FeatureOld ModelsGPT-5.6
Cache write costNo extra fee1.25x input rate
Cache read cost90% discount90% discount (unchanged)
ControlImplicit onlyImplicit + explicit breakpoints
TTLImplicit30m minimum (explicit prompt_cache_options.ttl)
Key matchingAutomaticMust set prompt_cache_key for reliable matching
Ergane caching strategy:
  • Set prompt_cache_key: "ergane:system-prompt:v1" for the stable system prompt (legal disclaimer + output schema)
  • Place explicit breakpoint after system prompt block
  • Per-request: diff text + prior art results (no breakpoint — changes every time)
  • This saves ~40% of input tokens on scans 2-N in a session

3.3 Tool Search (Deferred Loading)

Only gpt-5.4+ supports tool_search. The model searches for relevant tools instead of loading all upfront. Reduces token usage when tool surface is large.

{
  "model": "gpt-5.6-sol",
  "tools": [{
    "type": "tool_search",
    "tool_search": {
      "tool_directory": "/mcp/patent_tools"
    }
  }],
  "input": "I need to search patent databases and draft a claim"
}
# Model loads only patent_search_uspto, patent_search_epo, patent_draft_claim
# instead of all 111 MCP tools from patent-client-agents

5.2 Auto-Review Mode (Critical for Ergane)

Auto-Review: approvals_reviewer = "auto_review"
Routes eligible approval requests through a reviewer agent before surfacing to the user. The reviewer evaluates sandbox escalations, blocked network requests, and side-effecting MCP tool calls. Actions inside the sandbox continue without extra review. 
codex exec \
  --sandbox workspace-write \
  --ask-for-approval on-request \
  --config approvals_reviewer=auto_review \
  -m gpt-5.6-sol \
  "Verify prior art synthesis output against legal constraints before posting to GitHub"

6.2 Multi-Agent Beta (Responses API)

GPT-5.6 supports coordinating multiple subagents in parallel via the Responses API. Ergane uses this for the 3 parallel searches (USPTO + EPO + PQAI) in Stage 2.

{
  "model": "gpt-5.6-terra",
  "input": "Coordinate 3 parallel patent searches and synthesize results",
  "tool_choice": "required",
  "tools": [
    {"type": "function", "function": {"name": "search_uspto"}},
    {"type": "function", "function": {"name": "search_epo"}},
    {"type": "function", "function": {"name": "search_pqai"}}
  ],
  "reasoning": {"effort": "medium", "mode": "standard"}
}

6.3 ChatGPT Desktop Worktrees

The ChatGPT desktop app can run scheduled tasks in isolated Git worktrees. Each agent gets its own working directory + branch context.

Ergane worktree strategy:
  • Main loop runs in ~/ergane
  • Each codex exec invocation creates a temporary worktree under /tmp/ergane-wt-<uuid>/
  • The worktree contains a shallow clone of the target repo + the ergane state file
  • Prevents contamination between scans; allows parallel execution without git lock conflicts

8. Ergane Loop Engineering Harness

8.1 Harness Design Principles

  1. Model-tier routing: Luna for fast/filter tasks, Terra for balanced work, Sol for quality-first tasks
  2. Reasoning effort calibration: Never max on Luna (waste). Always low on Luna. Medium on Terra. High/max only on Sol when quality justify cost.
  3. Pro mode gating: Only Sol + pro mode for claim drafting. Standard mode for everything else.
  4. PTC for bounded pipelines: Use Programmatic Tool Calling when the tool sequence is predictable (3 patent searches → join → dedup)
  5. Cache the static prompt: Explicit breakpoint after system prompt. Saves ~40% tokens on repeated scans.
  6. Auto-review for safety: Enable approvals_reviewer=auto_review on Sol invocations that produce legal-adjacent output
  7. Worktree isolation: Each scan gets clean git state. No cross-contamination.
  8. Ultra for batch processing: When scanning N commits, spin 4 parallel Luna agents to partition the work

9. Concrete Codex Commands for Ergane

9.1 Stage 1: Detection

# Fast extraction — Luna, low reasoning, cache system prompt
codex exec \ -m gpt-5.6-luna \ --sandbox workspace-write \ --approval-mode never \ --config prompt_cache_key=ergane:stage1:v1 \ "$ergane-detect: Read the git diff between HEAD~1 and HEAD. Extract: technical_problem, technical_solution, key_claim_elements. Return strict JSON. No legal advice. Repository: $(pwd)"

9.2 Stage 2: Prior Art Search (Parallel)

# Parallel search — Terra, medium reasoning, PTC for 3 APIs
codex exec \ -m gpt-5.6-terra \ --sandbox workspace-write \ --approval-mode never \ --config prompt_cache_key=ergane:stage2:v1 \ "$ergane-prior-art: Search USPTO, EPO, and PQAI for prior art matching the invention description. Use programmatic tool calling to run searches in parallel, deduplicate, and return top 20 results ranked by combined similarity. Invention: {invention_json}"

9.3 Stage 3: Synthesis + Claim Draft

# High-quality synthesis — Sol, high reasoning, standard mode
codex exec \ -m gpt-5.6-sol \ --sandbox workspace-write \ --approval-mode on-request \ --config approvals_reviewer=auto_review \ --config prompt_cache_key=ergane:stage3:v1 \ "$ergane-synthesize: Compare invention against prior art table. Output: novelty_score (0-1), risk_assessment, draft_independent_claim. Use proper claim language. Include disclaimer. Prior art: {prior_art_json}"
# Pro mode escalation — only if novelty_score ≥ 0.7
codex exec \ -m gpt-5.6-sol \ --sandbox workspace-write \ --approval-mode on-request \ --config reasoning.mode=pro \ --config reasoning.effort=max \ --config approvals_reviewer=auto_review \ "Refine the draft independent claim. Verify: no software-per-se, proper antecedent basis, clear technical effect. This is pro-mode review."

9.4 Stage 4: Notification

# Fast formatting — Luna, low reasoning, PTC for webhook validation
codex exec \ -m gpt-5.6-luna \ --sandbox workspace-write \ --approval-mode never \ "$ergane-notify: Format PR comment (markdown) and OpenClaw webhook JSON. Validate payload against openclaw-schema.json. Results: {results_json}"

9.5 Batch Scan (Ultra Mode — 4 parallel agents)

# Ultra: 4 Luna agents partition 20 commits into 4 groups of 5
codex exec \ -m gpt-5.6-luna \ --sandbox workspace-write \ --approval-mode never \ --experimental multi-agent \ "Spawn 4 parallel subagents. Each scans 5 commits from the last 20. Each outputs novelty_score + technical_problem. Main agent synthesizes all 4 outputs into ergane-state.md."
