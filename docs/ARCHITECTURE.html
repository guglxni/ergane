2. System Overview

Ergane is a CLI tool + GitHub Action that detects potential patentable technical inventions in code commits, searches multiple patent databases via Coral SQL, synthesizes prior art similarity, drafts preliminary patent claims, and notifies teams.

6. Stage 1: Code Analysis

import pygit2
import graphify

def extract_commit_context(repo_path: str, since_ref: str, to_ref: str) -> dict:
    repo = pygit2.Repository(repo_path)
    since = repo.revparse_single(since_ref)
    to = repo.revparse_single(to_ref)
    diff = repo.diff(since, to)

    files_changed = [delta.new_file.path for delta in diff.deltas]

    g = graphify.Graphify()
    subgraph = g.query(
        repo_path=repo_path,
        query="Identify data processing and synchronization methods in modified files",
        files=files_changed,
    )

    return {
        "diff_text": diff.patch,
        "files_changed": files_changed,
        "subgraph": subgraph,
        "commit_message": to.message,
        "commit_hash": str(to.id)[:8],
    }

7.3 Multi-Source Coral SQL

WITH uspto_results AS (
    SELECT applicationNumberText AS patent_number, inventionTitle AS title,
           abstractText AS abstract, firstApplicantName AS assignee, 0.8 AS source_weight
    FROM uspto.patents WHERE q = 'vector clock cache invalidation' LIMIT 10
),
epo_results AS (
    SELECT doc_number AS patent_number, title, abstract, applicant AS assignee, 0.8 AS source_weight
    FROM epo.patents WHERE q = 'ti=distributed cache AND ab=vector clock' LIMIT 10
),
pqai_results AS (
    SELECT publication_number AS patent_number, title, abstract,
           NULL AS assignee, score AS source_weight
    FROM pqai.search_patents(query => 'distributed cache invalidation', top_k => 10)
)
SELECT * FROM uspto_results
UNION ALL SELECT * FROM epo_results
UNION ALL SELECT * FROM pqai_results
ORDER BY source_weight DESC LIMIT 20;

8. Stage 3: Synthesis (gpt-5.6-sol)

You are a patent claim analyst. Compare the following invention against prior art.

INVENTION:
- Technical problem: {technical_problem}
- Technical solution: {technical_solution}
- Key claim elements: {key_claim_elements}

PRIOR ART:
{cor_results_table}

Output JSON:
{
  "overall_similarity_score": float (0-100),
  "closest_patent": { "patent_number": "", "title": "", "source": "", "similarity_score": float },
  "risk_assessment": "NOVEL | POSSIBLY_NOVEL | LIKELY_PRIOR_ART",
  "draft_independent_claim": "string in USPTO format (Claim 1)",
  "recommendation": "PROCEED_WITH_FILING | REFINE_INVENTION | ABANDON"
}

Rules:
- Use proper claim language: "A method comprising..."
- NEVER claim software per se
- Include: "Preliminary draft for attorney review only."
- AI cannot be a co-inventor (USPTO Nov 2025 guidance)
