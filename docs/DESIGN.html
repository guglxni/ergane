### Technical Problem
Inconsistent cache state during network partitions in distributed systems.

### Technical Solution
Vector clock-based invalidation protocol with monotonic counters per cache node.

### Key Claim Elements
1. Maintaining a vector clock per cache node
2. Comparing vector clocks across nodes to detect stale entries
3. Atomic invalidation when partition heals

### Draft Independent Claim
```
1. A method for distributed cache invalidation comprising:
   maintaining a vector clock per cache node, each vector clock
   comprising a set of counters corresponding to other cache nodes;
   comparing vector clocks between nodes to detect entries that
   are stale relative to a network partition;
   and atomically invalidating the stale entries when the
   network partition heals.
```

> ⚠️ **Disclaimer:** This tool identifies potential technical inventions. It does not provide legal advice. Consult a patent attorney. AI cannot be a co-inventor.

### Recommendation
PROCEED_WITH_FILING — Prior art search shows 23% similarity to closest reference. The vector clock approach appears novel.

3. OpenClaw Notification Design

3.1 Gateway Configuration

{
  hooks: {
    enabled: true,
    token: "${OPENCLAW_HOOKS_TOKEN}",
    path: "/hooks",
    allowedAgentIds: ["ergane"],
    defaultSessionKey: "hook:ergane",
    allowRequestSessionKey: false,
    allowedSessionKeyPrefixes: ["hook:"],

    mappings: [
      {
        id: "ergane_invention",
        match: { path: "ergane" },
        action: "agent",
        name: "Ergane",
        messageTemplate: "🧠 Invention Detected: {{payload.invention_title}}\nNovelty: {{payload.novelty_score}}/1.0 | Risk: {{payload.risk_assessment}}\nEngineer: {{payload.inventor}} | Commit: {{payload.commit_hash_short}}\n\nProblem: {{payload.technical_problem}}\nClosest Prior Art: {{payload.closest_patent_title}} ({{payload.closest_patent_number}}) — {{payload.overall_similarity_score}}% similar\n\nReview: {{payload.github_pr_url}}",
        deliver: true,
        channel: "slack",
        to: "#inventions",
        model: "openai/gpt-5.6-luna",
        thinking: "medium"
      }
    ]
  }
}

6. Webhook Schemas

6.1 Ergane → OpenClaw

FieldTypeRequiredDescription
invention_titlestringYesShort title of invention
novelty_scorefloatYes0.0–1.0
risk_assessmentstringYesNOVEL, POSSIBLY_NOVEL, LIKELY_PRIOR_ART
inventorstringYesEmail or username
commit_hash_shortstringYes7-char hash
commit_urlstring (URL)YesFull commit URL
technical_problemstringYesTechnical problem description
closest_patent_titlestringNoTitle of closest prior art
closest_patent_numberstringNoPatent number
overall_similarity_scorefloatNo0–100%
github_pr_urlstring (URL)NoLink to review PR
dismiss_urlstring (URL)NoLink to dismiss notification

StatusMeaning
