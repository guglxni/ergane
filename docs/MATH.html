1. Novelty Score Model

The novelty score is a composite probability combining multiple signals into a single [0,1] score:

Novelty Score Equation: 
S_novelty = sigmoid( w₁·E_code + w₂·N_claims + w₃·T_domain + w₄·G_graph - b )

Where:
  E_code  = embedding distance between commit and known prior art
  N_claims = count of distinct claim elements / max_elements
  T_domain = technical domain specificity (IP classification confidence)
  G_graph  = Graphifyy subgraph complexity (nodes + edges normalized)
  w₁ + w₂ + w₃ + w₄ = 1.0 (learned weights)
  b = bias term (default 0.5)

Sigmoid Transformation

import math

def novelty_sigmoid(raw_score: float, beta: float = 1.0, bias: float = 0.5) -> float:
    """Compress raw score into [0,1] with tunable steepness.
    beta=1.0: smooth slope  |  beta=2.0: sharper discrimination
    """
    z = beta * (raw_score - bias)
    return 1.0 / (1.0 + math.exp(-z))

# Threshold mapping (no human calibration):
#  S >= 0.7 → HIGH     (likely novel, trigger full pipeline)
#  0.4 <= S < 0.7 → MEDIUM (ambiguous, may need expert review)
#  S < 0.4 → LOW      (routine, skip)

2. Transformer Embeddings for Patent Text

2.1 Sentence-BERT for Claim Comparison

For computing semantic similarity between invention descriptions and patent abstracts/claims.

Paper: "Sentence-BERT: Sentence Embeddings using Siamese BERT-Networks" (Reimers & Gurevych, EMNLP 2019)
Model: all-MiniLM-L6-v2 (384-dim) or multi-qa-mpnet-base-dot-v1 (768-dim) 
# Hermes: Architect defines embedding pipeline
# Codex: Implement in src/ergane/embeddings.py

from sentence_transformers import SentenceTransformer
import numpy as np

class PatentEmbedder:
    def __init__(self, model_name: str = "all-MiniLM-L6-v2"):
        self.model = SentenceTransformer(model_name)
        self.dim = self.model.get_sentence_embedding_dimension()

    def encode(self, texts: list[str]) -> np.ndarray:
        return self.model.encode(texts, normalize_embeddings=True)

    def similarity(self, embedding_a: np.ndarray, embedding_b: np.ndarray) -> float:
        # Cosine similarity (dot product of normalized vectors)
        return float(np.dot(embedding_a, embedding_b))

2.2 Matryoshka Embeddings (MRL)

Multi-resolution embeddings allow fast filtering (128-dim) then reranking (768-dim).

Paper: "Matryoshka Representation Learning" (Kusupati et al., NeurIPS 2022)
Application: PQAI returns 1024-dim vectors; Ergane uses first 256-dim for coarse filtering, full 1024-dim for final ranking. 
def matryoshka_similarity(emb_a: np.ndarray, emb_b: np.ndarray, dims: list[int]) -> float:
    """Weighted similarity across truncation levels."""
    total = 0.0
    weights = [0.2, 0.3, 0.5]  # 128-dim, 512-dim, full dim
    for d, w in zip(dims, weights):
        sim = float(np.dot(emb_a[:d], emb_b[:d]))
        total += w * sim
    return total / sum(weights)

3. Similarity Metrics for Prior Art

3.1 Combined Similarity Score

Overall Similarity: 
  sim_total = α·sim_semantic + β·sim_tfidf + γ·sim_ipc + δ·sim_temporal

  Where:
    sim_semantic = cosine(embeddings)              [0,1]
    sim_tfidf = BM25 score normalized              [0,1]
    sim_ipc = Jaccard(IPC codes)                   [0,1]
    sim_temporal = decay function of filing date   [0,1]
    α + β + γ + δ = 1.0

3.2 BM25 for Keyword Matching

Paper: "Okapi at TREC-3" (Robertson et al., 1994) — original BM25
Implementation: rank-bm25 Python package 
from rank_bm25 import BM25Okapi
import numpy as np

def bm25_similarity(query_tokens: list[str], patent_tokens: list[str], corpus: list[list[str]]) -> float:
    bm25 = BM25Okapi(corpus)
    scores = bm25.get_scores(query_tokens)
    max_score = max(scores) if scores.size > 0 else 1.0
    patent_score = bm25.get_scores(patent_tokens)[0] if patent_tokens else 0.0
    return patent_score / max_score

3.3 Temporal Decay Function

Earlier art is more damaging to novelty (first-to-file world):

def temporal_score(filing_year: int, current_year: int = 2026, half_life: float = 10.0) -> float:
    """Exponential decay. Older patents score higher (more dangerous to novelty).
    half_life=10: a 10-year-old patent scores 0.5
    """
    age = max(0, current_year - filing_year)
    return math.exp(-age / half_life)

# Examples:
#  2026 filing → score = 1.0 (most relevant)
#  2016 filing → score = 0.37
#  2006 filing → score = 0.14

def train_ranker(X_train, y_train, group_train):
    """y: 0=irrelevant, 1=partially_related, 2=close_prior_art, 3=anticipating
    group: number of patents per query
    """
    train_data = lgb.Dataset(X_train, label=y_train, group=group_train)
    params = {
        "objective": "lambdarank",
        "metric": "ndcg",
        "ndcg_eval_at": [1, 3, 5, 10],
        "boosting_type": "gbdt",
        "num_leaves": 31,
        "learning_rate": 0.05,
        "feature_fraction": 0.8,
    }
    model = lgb.train(params, train_data, num_boost_round=100)
    return model

4.2 NDCG@K Evaluation

Normalized Discounted Cumulative Gain: 
      K
  DCG = Σ (2^rel_i - 1) / log₂(i + 1)
     i=1

  NDCG@K = DCG / IDCG

  Where rel_i ∈ {0,1,2,3} is relevance grade of result at position i
  IDCG = ideal DCG (perfect ranking)

5. IPC/CPC Classification Math

5.1 Hierarchical Classification

IPC codes form a tree (e.g., G06F12/08 → G → G06 → G06F → G06F12 → G06F12/08). Similarity between two codes is their common prefix length normalized by max depth.

def ipc_similarity(code_a: str, code_b: str) -> float:
    """Jaccard-like similarity based on hierarchical prefix."""
    parts_a = code_a.replace('/', '-').split('-')
    parts_b = code_b.replace('/', '-').split('-')
    
    common = 0
    for pa, pb in zip(parts_a, parts_b):
        if pa == pb:
            common += 1
        else:
            break
    
    max_depth = max(len(parts_a), len(parts_b))
    return common / max_depth if max_depth > 0 else 0.0

# Examples:
# ipc_similarity("G06F12/08", "G06F12/10") = 0.8   (4/5 common parts)
# ipc_similarity("G06F12/08", "H04L67/10") = 0.0   (no common prefix)

5.2 IPC Distribution Entropy

Measure how "concentrated" the prior art is across IPC classes:

def ipc_entropy(ipc_codes: list[str]) -> float:
    """Higher entropy = more diverse prior art = harder to distinguish novelty."""
    from collections import Counter
    import math
    
    # Group by section (e.g., G06F → G)
    sections = [c[0] for c in ipc_codes if c]
    counts = Counter(sections)
    total = len(sections)
    
    entropy = 0.0
    for count in counts.values():
        p = count / total
        entropy -= p * math.log2(p)
    return entropy

# 5 patents all in 'G' → entropy ≈ 0.0
# 5 patents split G,H,C,B,A → entropy ≈ 2.32

6. Ensemble Scoring Pipeline

# Hermes: Defines ensemble weights and thresholds
# Codex: Implements in ergane/scoring.py

class NoveltyEnsemble:
    """Combines multiple scoring signals into final novelty assessment."""
    
    def __init__(self, weights: dict = None):
        self.weights = weights or {
            "semantic": 0.35,
            "bm25": 0.20,
            "ipc_overlap": 0.15,
            "temporal": 0.10,
            "graph_complexity": 0.20,
        }
        self.embedder = PatentEmbedder()
    
    def score(self, invention: dict, prior_art: list[dict]) -> dict:
        # Encode invention
        inv_emb = self.embedder.encode([invention["technical_solution"]])[0]
        
        # Score each prior art patent
        art_scores = []
        for patent in prior_art:
            art_emb = self.embedder.encode([patent["abstract"]])[0]
            sim_semantic = self.embedder.similarity(inv_emb, art_emb)
            sim_tfidf = bm25_similarity(
                invention["technical_solution"].split(),
                patent["abstract"].split(),
                [p["abstract"].split() for p in prior_art]
            )
            sim_ipc = ipc_similarity(invention["ipc"], patent.get("ipc", ""))
            sim_temporal = temporal_score(patent.get("filing_year", 2026))
            
            combined = (
                self.weights["semantic"] * sim_semantic +
                self.weights["bm25"] * sim_tfidf +
                self.weights["ipc_overlap"] * sim_ipc +
                self.weights["temporal"] * sim_temporal
            )
            art_scores.append({"patent": patent, "score": combined})
        
        # Best score = closest prior art
        art_scores.sort(key=lambda x: x["score"], reverse=True)
        closest = art_scores[0] if art_scores else None
        
        # Novelty = 1 - closest_similarity (inverse relationship)
        if closest:
            raw_novelty = 1.0 - closest["score"]
            novelty = novelty_sigmoid(raw_novelty, beta=2.0, bias=0.6)
        else:
            novelty = 1.0  # No prior art found = fully novel
        
        return {
            "novelty_score": round(novelty, 4),
            "novelty_assessment": self._assess(novelty),
            "closest_prior_art": closest["patent"] if closest else None,
            "closest_similarity": round(closest["score"], 4) if closest else 0.0,
            "all_scores": art_scores[:10],
            "ipc_entropy": round(ipc_entropy([p.get("ipc", "") for p in prior_art]), 4),
        }
    
    def _assess(self, score: float) -> str:
        if score >= 0.7:
            return "HIGH"
        elif score >= 0.4:
            return "MEDIUM"
        return "LOW"
