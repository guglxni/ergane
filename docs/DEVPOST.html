1. Hackathon Requirements (Official)

1.1 What to Build

Create a project using Codex with GPT-5.6. Must fit into one of these tracks:

TrackDescriptionErgane Fit
Apps for your lifeConsumer apps for everyday life — productivity, creativity, home, family, travel, health, personal finance❌ Not consumer-facing
Work and productivityTools that make teams faster or more effective — workflow automation, customer support, analytics, sales, back-office✅ Partial — teams use it
Developer ToolsTools for developers: testing, DevOps, agentic workflows, security✅ PRIMARY — CLI + GitHub Action + Codex subagents
EducationProjects that push AI for education — students, teachers, orgs❌ Not educational

1.2 Required Elements

  1. Working project — built with Codex using GPT-5.6
  2. Category — pick the track that fits best (Developer Tools)
  3. Project description — what you created and how it works
  4. Demo video — <3 minutes public YouTube video showing project working
    • Audio must cover how you used Codex AND GPT-5.6
    • Must show the tool in action
  5. Code repository URL — public or private shared with testing@devpost.com + build-week-event@openai.com
  6. README with setup instructions, sample data, clear guidance for running
  7. /feedback Codex Session ID — where majority of core functionality was built
  8. Highlight Codex acceleration — where key decisions were made, how GPT-5.6 and Codex were used
Judges will evaluate: Technical Implementation (Codex usage depth), Design (runnable product), Potential Impact (real problem, real audience), Quality of Idea (creativity, novelty).

Peter Steinberger ("Clawfather", Member of Technical Staff at OpenAI) is on the panel. He'll recognize genuine agentic workflows vs surface-level API wrapping.

8. ChatGPT Plugin / App Submission Path

8.1 Devpost Plugin (Already Exists)

The hackathon mentions a "Devpost Hackathons Plugin" that runs inside ChatGPT. This is NOT something we build — it's a Devpost-owned plugin for browsing hackathons.

8.2 Can Ergane Be a ChatGPT Plugin / GPT App?

PathFeasibilityEffortRecommendation
ChatGPT Plugin (legacy)Deprecated by OpenAIN/A❌ Don't pursue
GPTs / Custom GPTPossible but limited — no file system access, no gitLow⚠️ Weak fit — Ergane needs CLI + git
ChatGPT Desktop App with WorktreesCodex desktop app supports scheduled tasks + skillsMedium✅ Good stretch — submit as "also works in Codex desktop"
MCP ServerExpose Ergane as MCP so other agents can call itLow-Medium✅ Good addition — makes it composable
GitHub Action + CLICore deliverable, fully functionalMedium✅ PRIMARY — focus here

8.3 Recommended: Package as Both CLI + MCP Server

# Ergane as MCP server — other agents can invoke patent search
{
  "mcpServers": {
    "ergane": {
      "command": "python3",
      "args": ["-m", "ergane.mcp"],
      "env": {
        "OPENAI_API_KEY": "${OPENAI_API_KEY}",
        "ERGANE_MODEL": "gpt-5.6-sol"
      }
    }
  }
}

Submission framing: "Ergane is a CLI tool and GitHub Action for developer teams. It also exposes an MCP server for agent composability, making it usable from any Codex/Cursor/Claude Code session."
