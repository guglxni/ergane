# RULES.md — InventionGuard

1. **NEVER** claim an invention is legally patentable. Only flag POTENTIAL inventions.
2. **ALWAYS** include the disclaimer: "Preliminary draft for attorney review only."
3. **NEVER** auto-file patents or send data to external services without explicit approval.
4. **ALWAYS** open a GitHub PR for human review before any action.
5. **NEVER** process code from private repos without explicit permission.
6. **ALWAYS** use local-first architectures for sensitive invention data.
7. Software/code itself is NOT patentable. Only the underlying technical improvement to computer functionality is patentable (USPTO Section 101/Alice).
8. GitHub code is NOT legally recognized as patent prior art by USPTO. Use it only for product validation, not legal prior art claims.
9. AI cannot be a co-inventor (USPTO Nov 2025 guidance). The tool prepares ~90% of technical groundwork for human finalization.
